# Computer Vision and Image Processing

A collection of Python experiments exploring image processing and computer vision techniques using OpenCV.

# Overview

This project covers several techniques for image manipulation, analysis, and feature detection.

# Image Processing

- Image cropping and resizing
- Color space transformations: Grayscale, HSV, and LAB
- Color channel separation and recombination
- Image smoothing and blurring
- Noise reduction and image enhancement
- Histogram analysis and equalization

# Masks and Bitwise Operations

- Creating geometric masks
- Applying bitwise AND, OR, XOR, and NOT operations
- Selecting and extracting specific image regions

# Edge and Contour Detection

- Canny edge detection
- Sobel and Laplacian filters
- Morphological operations: dilation and erosion
- Contour detection and visualization
- Binary thresholding

# Image Restoration

- Image inpainting for removing unwanted marks
- Colored image denoising

# Face Detection

- Face detection using Haar cascade classifiers
- Drawing bounding boxes around detected faces

# Getting Started

1. Open the notebook in Google Colab or Jupyter Notebook.
2. Upload the required input images when prompted.
3. Make sure the Haar cascade XML files are available and their paths are configured correctly.
4. Run the notebook cells to explore the techniques and visualize the results.

# Purpose

This project is a practical exploration of classical computer vision and image processing methods, with a focus on understanding image transformations, feature extraction, and detection techniques.
